O **Wired Variável: Usuário Variável** permite criar informações e associá-las aos usuários do quarto. Quer guardar a pontuação de um jogador, identificar quem participa de uma partida ou marcar um bot como vendedor? Você pode utilizar uma variável de usuário para isso.

<Infobox />

No Habbo, **usuário** não significa apenas um jogador: **bots e mascotes** também fazem parte desse grupo. Cada um possui características que o jogo disponibiliza automaticamente, como tipo, posição e direção. Este Wired permite criar suas próprias informações.

## Como esse Wired funciona?

O primeiro passo é **criar a variável**. Nesta etapa, você define seu nome, se ela armazena um número e por quanto tempo ficará disponível.

Ao abrir a janela de configuração, você encontra três seções: **Nome da variável**, **Configurações da variável** e **Opções de disponibilidade**.

![Janela do Wired Usuário Variável com o campo Nome da variável vazio, a opção Tem valor desmarcada e a disponibilidade Enquanto o usuário está no quarto selecionada.](@assets/wf_var_user/01-janela-do-wired.png)

### Nome da variável

Defina o nome que será utilizado para identificar a variável. O campo aceita entre **1 e 40 caracteres**, utilizando apenas **letras, números e sublinhado (`_`)**.

Se você utilizar um espaço no nome, ele será substituído automaticamente por um **sublinhado (`_`)**. Por exemplo, `pontos do jogador` se torna `pontos_do_jogador`.

Prefira nomes que ajudem a entender o que a variável representa, como `pontuacao`, `participando_do_jogo` ou `vendedor`.

O nome precisa ser **único no quarto**, mesmo entre variáveis de tipos diferentes. Se outro Wired de variável já utilizar esse nome, ao tentar salvar a configuração aparecerá a mensagem **"Esse nome de variável já está em uso neste quarto, escolha um nome diferente!"**. Escolha outro nome para conseguir salvar.

![Janela Falha ao atualizar avisando que o nome de variável já está em uso no quarto e solicitando um nome diferente.](@assets/wf_var/04-janela-de-aviso-nome-de-variavel-ja-em-uso.png)

### Configurações da variável

A opção **Tem valor** define se a variável armazena um número ou apenas indica a presença de uma característica:

| Opção | Como funciona | Exemplo |
| :--- | :--- | :--- |
| **Marcada** | A variável pode armazenar um valor numérico. | `pontuacao` guarda os pontos de cada jogador. |
| **Desmarcada** | A variável funciona como uma informação de verdadeiro ou falso, conforme esteja vinculada ao usuário ou não. | `participando_do_jogo` identifica quem está na partida. |

No exemplo de uma variável sem valor, estar vinculada ao usuário representa **verdadeiro**. Se ela não estiver vinculada, representa **falso**. Você não precisa armazenar os números 1 e 0 para fazer essa distinção.

#### Valores que a variável pode armazenar

Com a opção **Tem valor** marcada, a variável armazena números inteiros positivos, negativos ou zero. Consulte [Valores que a variável pode armazenar](/referencia/variaveis/visao-geral/#valores-que-a-variável-pode-armazenar) na visão geral para entender os limites de armazenamento e de exibição no cliente Clássico.

### Opções de disponibilidade

Esta seção define por quanto tempo a variável fica associada ao usuário e se ela pode ser acessada por outros quartos.

| Opção | Como funciona |
| :--- | :--- |
| **Enquanto o usuário está no quarto** | A associação é mantida enquanto o usuário permanece no quarto. Ao sair, ele perde essa variável. |
| **Permanente** | A associação é mantida mesmo depois que o usuário sai do quarto, até que seja removida ou a variável seja excluída. |
| **Permanente, compartilhado entre quartos** | Além de permanecer associada ao usuário, a variável pode ser acessada em outros quartos por meio do [Wired Variável: De Outro Quarto](/referencia/variaveis/wf_var_reference/). |

Por exemplo, uma marcação de participação em uma atividade pode existir apenas durante a visita ao quarto. Já uma pontuação que o jogador deve conservar para a próxima visita pode utilizar a opção **Permanente**.

Em um labirinto com fases distribuídas entre vários quartos, a opção **Permanente, compartilhado entre quartos** pode guardar o último **checkpoint** alcançado pelo jogador. Os outros quartos podem consultar essa variável por meio do **[Wired Variável: De Outro Quarto](/referencia/variaveis/wf_var_reference/)**, permitindo que o sistema reconheça seu progresso e o encaminhe à fase correspondente quando ele voltar a jogar.

<Aside type="note" title="Compartilhamento apenas no próprio quarto">
A opção **Permanente, compartilhado entre quartos** só pode ser configurada em um quarto do qual você é dono. Se você colocar este Wired no quarto de grupo de um amigo e tentar salvar com essa opção selecionada, aparecerá a mensagem **“Você só pode definir variáveis como compartilhadas em seu próprio quarto.”**, e a configuração não será salva.

![Janela Falha ao atualizar com a mensagem Você só pode definir variáveis como compartilhadas em seu próprio quarto e o botão Ok.](@assets/wf_var/03-janela-de-aviso-ao-tentar-criar-variavel-compartilhada.png)
</Aside>

<Aside type="caution" title="Ao alterar a disponibilidade">
Se você configurar a variável como **Permanente** e depois tentar mudar para **Enquanto o usuário está no quarto**, o jogo abrirá uma janela com a mensagem:

![Janela Limpando os dados das variáveis avisando que alterar a disponibilidade apagará todos os dados armazenados de forma irreversível, com os botões Cancelar e Ok.](@assets/wf_var_user/07-janela-limpando-os-dados-das-variaveis.png)

Com a nova disponibilidade, os usuários que estão fora do quarto não poderiam manter a variável associada a eles. Para aplicar a mudança igualmente a todos, o jogo apaga os dados dessa variável de **todos os usuários**, inclusive daqueles que estão no quarto. Por isso, confirme apenas se estiver de acordo em perder os valores armazenados. Essa ação não pode ser desfeita.
</Aside>

## Vincular a variável a um usuário

Depois de confirmar a configuração, a variável aparece na lista do alvo **Usuário** na aba [Variáveis das Ferramentas do Criador](/referencia/ferramentas-do-criador/variaveis/). Porém, **criar a variável não significa vinculá-la automaticamente a algum usuário**.

Você pode fazer essa associação por uma pilha Wired ou manualmente pela aba **Inspeção**. Nos exemplos abaixo, vamos utilizar a variável `rating_wired_club` para conhecer as duas formas.

### Pelo Efeito Wired: Dar Variável

O [Efeito Wired: Dar Variável](/referencia/efeitos/wf_act_give_var/) permite atribuir a variável aos usuários definidos na configuração da pilha. Imagine que você queira fazer isso para quem estiver em uma área do quarto: nesse caso, um seletor pode determinar quem receberá a variável.

Para montar o exemplo, crie `rating_wired_club` com **Tem valor**. Depois, selecione essa variável no Efeito **Dar Variável**, mantenha o valor inicial em **0** e escolha **Usar usuários do seletor** como destino.

A área será definida pelo **Seletor Wired: Habbos na Área**. Já o **Ativador Wired: Repetir Efeito**, configurado com um intervalo de **10 segundos**, acionará a pilha para atribuir a variável aos usuários selecionados.

O vídeo abaixo mostra essa configuração e a conferência do resultado pelo botão [Destacar](/referencia/ferramentas-do-criador/variaveis/#destacar), na aba **Variáveis**. Os alvos ficam realçados, e os balões com o valor **0** ajudam a visualizar a associação feita pelo sistema.

No formulário, escolha `rating_wired_club`, informe o **Valor** e confirme em **Criar**. A variável passará a aparecer na lista desse usuário.

## Alterar o valor da variável

Depois de criar a variável e vinculá-la a um usuário, você pode modificar o número que ela armazena. Isso permite, por exemplo, aumentar uma pontuação conforme o jogador realiza uma ação no quarto.

Essa alteração se aplica às variáveis com **Tem valor** marcado. Para uma variável sem valor, como `participando_do_jogo`, o que importa é atribuí-la ou removê-la do usuário.

Você pode alterar o valor por um Efeito Wired ou diretamente pela aba **Inspeção** das Ferramentas do Criador.

### Pelo Efeito Wired: Mudar Valor Variável

Para fazer essa alteração pelo sistema, utilize o [Efeito Wired: Mudar Valor Variável](/referencia/efeitos/wf_act_change_var_val/). Selecione `rating_wired_club`, escolha a operação **Somar** e informe **1** como valor de referência. Confira também a fonte de usuários: ela determina quais usuários terão seus valores alterados quando a pilha for acionada.

Se um jogador possui `rating_wired_club` com valor **0**, essa operação faz seu valor passar para **1**. Cada usuário mantém seu próprio valor, então os demais só serão afetados se também estiverem entre os alvos do Efeito.

## Exibir o valor da variável no quarto

Até aqui, utilizamos as **Ferramentas do Criador** para consultar e conferir os valores. Como nem todos os participantes têm acesso a essas ferramentas, você pode exibir a informação diretamente no quarto para que ela faça parte da experiência do jogo.

Uma forma simples é utilizar a [Variável FX: Exibição de Números](/referencia/variaveis/wf_xtra_varfx_number/). Coloque esse Wired acima do **Wired Variável: Usuário Variável** que define `rating_wired_club`. O efeito visual mostrará o valor acima dos usuários que possuem a variável.

Depois, configure o estilo e a visibilidade do número. Se quiser que todos no quarto possam acompanhá-lo, escolha a audiência **Todos**; para que o próprio jogador veja seu valor, escolha **Somente o usuário**. A opção **Sempre visível** pode ajudar a acompanhar as mudanças durante o exemplo.

Assim, quando o Efeito **Mudar Valor Variável** somar **1**, o número exibido acompanhará o novo valor. A Variável FX apresenta a informação armazenada; a atribuição e a alteração continuam sendo feitas pelas etapas anteriores.

Para alterar o nome de uma variável já criada, clique duas vezes no **Wired Variável: Usuário Variável**, edite o campo **Nome da variável** e confirme a alteração.

Depois de confirmar, o novo nome passa a aparecer em todos os locais das **Ferramentas do Criador** que fazem referência a essa variável, como a lista da aba **Variáveis** e a tabela da aba **Inspeção**.

## Retirar o Wired do quarto

Ao tentar retirar este Wired depois de criar e vincular a variável, aparece uma janela pedindo confirmação. Ela informa que todas as referências à variável e todos os dados armazenados por ela serão apagados.

![Janela Removendo uma variável avisando que todas as referências e os dados armazenados serão apagados, com as opções Cancelar e Ok.](@assets/wf_var/02-janela-de-aviso-ao-remover-wired.png)

Você também pode excluir a variável pela aba **Variáveis** das Ferramentas do Criador. Selecione-a na lista e utilize o ícone de excluir no rodapé, conforme explicado em [Excluir uma variável](/referencia/ferramentas-do-criador/variaveis/#excluir-uma-variável). A ação pede confirmação, afeta todos os usuários que possuem a variável e não pode ser desfeita.

<Aside type="caution" title="Confira antes de remover">
Retirar o Wired ou excluir a variável pela aba Variáveis afeta a definição e os dados associados a ela. Se você quer apenas desvinculá-la de um usuário específico, utilize a opção [Remover variável](/referencia/ferramentas-do-criador/inspecao/#remover-variável) na aba Inspeção.
</Aside>

## Variáveis internas de usuário

Jogadores, bots e mascotes possuem variáveis internas, viculadas automaticamente pelo Habbo, mas nem todas estão disponíveis para todos esses tipos de usuário. A lista abaixo reúne as que são **comuns a todos eles**.

Essas variáveis possuem a propriedade **Sempre disponível** definida como **Sim** (verdadeiro). Isso significa que elas existem em todos os usuários, conforme explicado em [O que significa estar sempre disponível?](/referencia/ferramentas-do-criador/variaveis/#o-que-significa-estar-sempre-disponível).

Para consultar todas as variáveis que os usuários podem ter, incluindo as que dependem do tipo de usuário ou de condições específicas, acesse a aba [Variáveis das Ferramentas do Criador](/referencia/ferramentas-do-criador/variaveis/) e selecione o alvo **Usuário**. Já a aba [Inspeção](/referencia/ferramentas-do-criador/inspecao/) permite conferir quais variáveis estão vinculadas a um usuário específico.

| Variável | O que representa |
| :--- | :--- |
| `@index` | O índice atribuído ao usuário quando entra no quarto. A contagem começa em **0** depois que o quarto é carregado. Se o usuário sair e entrar novamente, recebe um novo índice. |
| `@type` | O tipo do usuário: jogador, mascote, bot de espaços públicos ou bot comprado na loja. Confira o tópico [Tipo de usuário](#tipo-de-usuário) para mais detalhes |
| `@gender` | O gênero do usuário. Mascotes utilizam o valor correspondente a desconhecido. Confira o tópico [Gênero](#gênero) para mais detalhes |
| `@level` | O nível da conta do jogador. Bots e mascotes recebem **0**. |
| `@achievement_score` | A quantidade de pontos de conquista da conta. Bots e mascotes recebem **0**. |
| `@position.x` | A posição do usuário no eixo **X** (horizontal) do quarto. |
| `@position.y` | A posição do usuário no eixo **Y** (vertical) do quarto. |
| `@direction` | A direção para a qual o usuário está voltado. Confira o tópico [Direção](#direção) para mais detalhes |
| `@altitude` | A altitude do usuário no quarto. |
| `@room_entry.method` | A forma como o usuário entrou no quarto. Confira o tópico [Forma de entrada no quarto](#forma-de-entrada-no-quarto) para mais detalhes |

As variáveis `@type`, `@gender`, `@direction` e `@room_entry.method` possuem textos associados aos seus valores numéricos. As tabelas abaixo mostram o significado de cada valor.

### Tipo de usuário

A variável `@type` permite distinguir os diferentes tipos de usuário:

| Valor | Tipo |
| :--- | :--- |
| **1** | Jogador. |
| **2** | Mascote. |
| **3** | Bot de espaços públicos. Por exemplo: a Aninha Pixel do Clube de Boas-Vindas ou o Juarez do Cafézinho |
| **4** | Bot comprado na loja. |

### Gênero

A variável `@gender` utiliza os seguintes valores:

| Valor | Gênero |
| :--- | :--- |
| **-1** | Desconhecido, utilizado para mascotes. |
| **0** | Masculino. |
| **1** | Feminino. |

### Direção

A variável `@direction` representa uma das oito direções:

| Valor | Direção | Representação do usuário |
| :--- | :--- | :---: |
