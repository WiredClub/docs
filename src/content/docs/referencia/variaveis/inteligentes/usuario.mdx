Alguns usuários possuem variáveis inteligentes próprias. Seus nomes começam com `~` (til), e a lista de variáveis do quarto só mostra aquelas relacionadas aos elementos que estão presentes nele.

Para procurar essas variáveis, abra a aba [Variáveis das Ferramentas do Criador](/referencia/ferramentas-do-criador/variaveis/#como-acessar) e selecione o alvo **Usuário**. Na aba [Inspeção](/referencia/ferramentas-do-criador/inspecao/), você pode conferir as variáveis associadas a um usuário específico.

Estes são alguns prefixos documentados para tipos de usuário:

| Usuário | Prefixo |
| :--- | :--- |
| Mascotes | `~pet` |
| Plantas Monstro | `~plant` |
| Cavalos | `~horse` |

Os prefixos ajudam a reconhecer o grupo ao qual uma variável pertence. Para conhecer o nome completo e as propriedades de uma variável, consulte a lista no quarto com o usuário correspondente presente. As [variáveis internas de usuário](/referencia/variaveis/internas/usuario/) aparecem com o prefixo `@` e têm outra finalidade.
