Jogadores, bots e mascotes possuem variáveis internas, vinculadas automaticamente pelo Habbo, mas nem todas estão disponíveis para todos esses tipos de usuário. A lista abaixo reúne as que são **comuns a todos eles**.

Para consultar todas as variáveis que os usuários podem ter, incluindo as que dependem do tipo de usuário ou de condições específicas, acesse a aba [Variáveis das Ferramentas do Criador](/referencia/ferramentas-do-criador/variaveis/) e selecione o alvo **Usuário**. Já a aba [Inspeção](/referencia/ferramentas-do-criador/inspecao/) permite conferir quais variáveis estão vinculadas a um usuário específico.

## Variáveis sempre disponíveis

Essas variáveis possuem a propriedade **Sempre disponível** definida como **Sim** (verdadeiro). Isso significa que elas existem em todos os usuários, conforme explicado em [O que significa estar sempre disponível?](/referencia/ferramentas-do-criador/variaveis/#o-que-significa-estar-sempre-disponível).

| Variável | O que representa |
| :--- | :--- |
| `@index` | O índice atribuído ao usuário quando entra no quarto. A contagem começa em **0** depois que o quarto é carregado. Se o usuário sair e entrar novamente, recebe um novo índice. |
| `@type` | O tipo do usuário: jogador, mascote, bot de espaços públicos ou bot comprado na loja. Confira o tópico [Tipo de usuário](#tipo-de-usuário) para mais detalhes |
| `@gender` | O gênero do usuário. Mascotes utilizam o valor correspondente a desconhecido. Confira o tópico [Gênero](#gênero) para mais detalhes |
| `@level` | O nível da conta do jogador. Bots e mascotes recebem **0**. |
| `@achievement_score` | A quantidade de pontos de conquista da conta. Bots e mascotes recebem **0**. |
| `@position.x` | A posição do usuário no eixo **X** (horizontal) do quarto. |
| `@position.y` | A posição do usuário no eixo **Y** (vertical) do quarto. |
| `@direction` | A direção para a qual o usuário está voltado. Confira o tópico [Direção](#direção) para mais detalhes |
| `@altitude` | A altitude do usuário no quarto. |
| `@room_entry.method` | A forma como o usuário entrou no quarto. Confira o tópico [Forma de entrada no quarto](#forma-de-entrada-no-quarto) para mais detalhes |

As variáveis `@type`, `@gender`, `@direction` e `@room_entry.method` possuem textos associados aos seus valores numéricos. As tabelas abaixo mostram o significado de cada valor.

### Tipo de usuário

A variável `@type` permite distinguir os diferentes tipos de usuário:

| Valor | Tipo |
| :--- | :--- |
| **1** | Jogador. |
| **2** | Mascote. |
| **3** | Bot de espaços públicos. Por exemplo: a Aninha Pixel do Clube de Boas-Vindas ou o Juarez do Cafézinho |
| **4** | Bot comprado na loja. |

### Gênero

A variável `@gender` utiliza os seguintes valores:

| Valor | Gênero |
| :--- | :--- |
| **-1** | Desconhecido, utilizado para mascotes. |
| **0** | Masculino. |
| **1** | Feminino. |

## Variáveis que nem sempre estão disponíveis
Estas variáveis possuem **Sempre disponível** definido como **Não** (falso). Isso indica que a variável pode não existir para determinado usuário ou em determinado momento

| Variável | Quando está disponível | O que representa |
| :--- | :--- | :--- |
| `@is_idle` | Quando o usuário está ausente (dormindo). | Indica esse estado. |
| `@team.score` | Ao entrar em uma equipe. | Pontuação total da equipe. |
| `@team.color` | Ao entrar em uma equipe.  | A cor da equipe do usuário. |
| `@team.type` | Ao entrar em uma equipe.  | Qual tipo de jogo o usuário está. |

### Equipe

Caso o usuário possua variáveis com o prefixo `@team.`, isso indica que elas estão relacionadas a equipes de jogos, como **Battle Banzai**, **Freeze** ou **Wired**. Conhecer essas variáveis é importante, pois determinados Wireds podem utilizá-las para verificar ou modificar informações relacionadas as equipes.

`@team.score`: Armazena a pontuação total de cada equipe, com base na cor que a identifica.

Isso significa que a pontuação é **compartilhada entre todos os jogadores que pertencem a mesma cor de equipe**.

**Exemplo**: imagine que há quatro jogadores da equipe vermelha participando de uma partida de Battle Banzai. Se um deles marcar 5 pontos, os outros três também terão esses 5 pontos contabilizados em suas respectivas variáveis `@team.score`.

É importante destacar que, embora seja possível ter partidas de **Battle Banzai**, **Freeze** e **Wired** acontecendo simultaneamente no mesmo quarto, **o sistema compartilha a pontuação entre os jogos** quando os jogadores pertencem à mesma equipe (mesma cor).

Por exemplo, se a equipe vermelha marcar 5 pontos no Battle Banzai, todos os jogadores da equipe vermelha que estiverem jogando Freeze ou Wired **também receberão esses 5 pontos**, mesmo sem terem participado da partida de Battle Banzai.

**Recomendação:** para evitar conflitos na pontuação e garantir que cada jogo tenha seu próprio placar, considere criar um quarto separado para cada modalidade.

É possível alterar diretamente essa variável utilizando o [Efeito: Mudar Valor Variável](/referencia/efeitos/wf_act_change_var_val/).

<Aside type="note" title="Nota importante">

Essa variável só pode ser modificada quando existe um mobi do **tipo cronômetro** no quarto que atende às seguintes condições:

- A variável inteligente `~clock.is_game_aware` existe no cronômetro.
- A variável inteligente `~clock.state` deve ser igual a 1.

Se essas condições **não forem atendidas**, a variável `@team.score` **não poderá ser alterada**.

Para entender melhor o funcionamento das variáveis inteligentes, recomendamos a leitura da seção sobre [Cronômetros](/referencia/variaveis/inteligentes/mobi/#cronômetros).

</Aside>

<Aside type="caution" title="Atenção para as próximas variáveis">
Não é possível alterar diretamente `@team.color` e `@team.type` utilizando o [Efeito: Mudar Valor Variável](/referencia/efeitos/wf_act_change_var_val/).
</Aside>

`@team.color`: Define a cor da equipe à qual o usuário pertence. Essa cor pode ser **atribuída ou alterada de diferentes maneiras**, como por meio do Wired [Efeito: Entrar na equipe](/referencia/efeitos/wf_act_join_team/) ou ao passar por um dos portões de equipe dos jogos Battle Banzai e Freeze.

Se o usuário quiser mudar de cor em uma partida de Battle Banzai ou Freeze, será necessário que ele saia do quarto ou saia da equipe pelo respectivo portão e entre novamente pelo portão correspondente à cor desejada.

<Aside type="note" title="Nota">
Não é possível passar por um portão Battle Banzai ou Freeze quando uma partida estiver em andamento!
</Aside>

O mesmo princípio se aplica quando o tipo da equipe é Wired. Nesse caso, será necessário construir um sistema próprio para permitir que o usuário escolha e altere a cor da equipe, utilizando o [Efeito: Entrar na equipe](/referencia/efeitos/wf_act_join_team/).

Dessa forma, a mudança de cor deve ser realizada por meio dos mecanismos de entrada e saída de equipes, e não pela alteração direta da variável.

A cor da equipe é representada por valores numéricos, permitindo que os Wireds identifiquem e manipulem a equipe à qual o usuário pertence.

Os valores numéricos correspondentes a cada cor são:

| Valor | Cor | 
| :--- | :--- |
| 1 | Vermelho (Red) | 
| 2 | Verde (Green) | 
| 3 | Azul (Blue) | 
| 4 | Amarelo (Yellow) | 

`@team.type`: Define o tipo de equipe à qual o usuário pertence, identificando em qual modalidade de jogo ele está participando, como Battle Banzai, Freeze ou Wired.

Essa variável é importante porque determina o contexto da equipe e permite que os Wireds identifiquem a qual tipo de jogo o usuário está associado. Dependendo do valor definido em `@team.type`, o usuário poderá receber **efeitos** e **comportamentos específicos** relacionados ao respectivo jogo.

Assim como `@team.color`, para o usuário mudar o tipo de equipe ele terá que sair da equipe atual e escolher a nova.

Além disso, essa variável permite diferenciar equipes de modalidades distintas, mesmo quando possuem a mesma cor.

Os valores numéricos correspondentes a cada tipo são:


| Valor | Jogo |
| :--- | :--- |
| 0 | Battle Banzai |
| 1 | Freeze |
| 2 | Tagging |
| 3 | Swimming |
| 4 | Wired |

#### Restrições e funcionamento das variáveis de equipe

Um usuário **não pode** participar de mais de uma equipe ao mesmo tempo. Isso significa que ele não pode estar simultaneamente em uma equipe do tipo Wired e em uma equipe do tipo Battle Banzai, por exemplo, mas **pode receber pontuações de ambas.**

Além disso, quando o usuário perde uma das variáveis com o prefixo `@team.`, isso indica que ele saiu da equipe à qual pertencia.

Nesse caso, todas as demais variáveis que possuem o mesmo prefixo (`@team.`) terão seus valores zerados e removidos do usuário.

<Aside type="note" title="Importante">
A ausência de qualquer uma dessas variáveis indica que o usuário **não está associado** a nenhuma equipe.
</Aside>
