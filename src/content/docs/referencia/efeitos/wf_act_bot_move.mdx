O **EFEITO WIRED: Bot se muda ao Mobi** faz com que um ou mais bots, definidos nas configurações avançadas, se desloquem para o espaço e a posição ocupados pelos mobis selecionados.

<Infobox />

## Configuração
**Nome do bot**: Escreva o nome do bot que o efeito será aplicado, é importante conferir se o bot está com o mesmo nome e está no quarto.

## Configurações avançadas

**Selecione a fonte do mobi:**
- Use mobis escolhidos
- Usar mobis do seletor
- Usar mobis do sinal
- Use o item de ativação

**Selecione Bot fonte:**
- Use o bot especificado pelo nome
- Usar usuários do seletor
- Usar usuários do sinal
- Use o usuário acionador
